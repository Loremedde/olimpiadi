# Report e Analisi dei dati Open Milano Cortina 2026
[![CC0](https://licensebuttons.net/p/zero/1.0/88x31.png)](https://creativecommons.org/publicdomain/zero/1.0/)


Questo repository contiene codice, report, grafici e collegamenti a fonti per l'analisi della situazione
attuale dei progetti infrastrutturali in previsione delle Olimpiadi Milano - Cortina 2026.

I dati utilizzati sono pubblici, aperti e liberamente scaricabili da chiunque dal sito di **SIMICO S.p.A**
(Società Infrastrutture Milano Cortina). [https://www.simico.it/piano-delle-opere/](https://www.simico.it/piano-delle-opere/)
